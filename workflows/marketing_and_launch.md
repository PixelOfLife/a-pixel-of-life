# Marketing & Launch Strategy: "A Pixel of Life"

## 1. Monetization Strategy (Cash Flow Inmediato)

### Modelo Recomendado: Freemium con Capítulos Premium
Basado en la investigación de mercado de 2025/2026, el modelo más efectivo para este tipo de juego narrativo en móvil es:

| Estrategia | Implementación |
|---|---|
| **Capítulo 1 (Gratis)** | El "Útero". 10-15 min de gameplay. Funciona como demo y gancho. |
| **Capítulos 2-5 (Premium)** | Venta por capítulo ($1.99-$2.99) o pase de temporada ($6.99). |
| **Cosméticos (IAP)** | "Vibraciones" visuales, efectos de latido especiales, fondos personalizados. |
| **Pase de Emociones (Battle Pass)** | Temporada de 30 días con recompensas de cosméticos y contenido narrativo exclusivo. |

**Por qué este modelo:**
- El Capítulo 1 gratuito elimina la barrera de entrada (maximiza descargas).
- Genera ingresos desde el Capítulo 2, validando la demanda temprano.
- Los cosméticos son éticos y no afectan la jugabilidad.
- El precio de $1.99-$2.99 por capítulo está dentro del rango óptimo para móviles.

### Flujo de Ingresos Proyectado (Mes 1)
- Descargas gratuitas (Cap 1): 1,000 - 5,000 (orgánico + ads)
- Conversión a Cap 2 (estimado 10-15%): 100 - 750 ventas
- Ingresos estimados: $200 - $2,250 USD (solo Cap 2)

## 2. Plataformas de Assets Gratuitos (Pixel Art de Calidad)

### Herramientas de Edición (Gratuitas)
| Herramienta | Tipo | Ideal Para |
|---|---|---|
| **Piskel** | Editor Online | Principiantes, sprites rápidos, prototipos |
| **Aseprite** | Desktop ($20 o compilar gratis) | Estándar de la industria, animaciones complejas |
| **Libresprite** | Desktop (Open Source) | Alternativa gratuita a Aseprite |
| **GraphicsGale** | Desktop (Windows) | Ligero, bueno para sprites simples |

### Generadores de Assets con IA (Gratuitos)
| Herramienta | Capacidades | Notas |
|---|---|---|
| **PixelVibe (Rosebud AI)** | Sprites, tilesets, isométrico | Gratis, genera en tamaños específicos (16x16 a 128x128) |
| **Sprite-AI** | Sprites con editor integrado | Tamaño gratuito limitado |
| **Imagine.Art** | Escenas, fondos, tiles | Exporta sin marca de agua |
| **GameNGen** | Sprite sheets animados | Generador local (sin subida de datos), semilla para reproducibilidad |

## 3. Requisitos de las Tiendas (Normativas de Publicación)

### Apple App Store ($99/año)
| Requisito | Detalle |
|---|---|
| **Cuenta** | Apple Developer Program activo ($99/año) |
| **Bundle ID** | Registrado en Certificates, Identifiers & Profiles |
| **Icono** | Todos los tamaños requeridos (1024x1024 principal) |
| **Screenshots** | Para cada tamaño de dispositivo soportado |
| **Política de Privacidad** | URL activa y accesible HTTPS |
| **App Privacy** | Declaración de datos recolectados completada |
| **Demo Account** | Si hay login, credenciales para revisores |
| **Contenido** | Sin texto placeholder, sin crashes, sin TODOs |
| **IAP** | Usar StoreKit, botón "Restore Purchases" |
| **Review Time** | 24-72 horas (90% en 24h) |

### Google Play Store ($25 único)
| Requisito | Detalle |
|---|---|
| **Cuenta** | Developer Account ($25 pago único) |
| **Formato** | Android App Bundle (AAB, no APK) |
| **Icono** | 512x512 PNG con transparencia |
| **Feature Graphic** | 1024x500 PNG (obligatorio para publicar) |
| **Screenshots** | Mínimo 2, hasta 8 por tamaño |
| **Política de Privacidad** | URL activa |
| **Data Safety** | Sección completa de seguridad de datos |
| **Target API** | Android 14+ (API 34) mínimo |
| **Testing** | Cuentas nuevas requieren 14 días de testing cerrado |
| **Review Time** | Horas a 7 días |

### Assets Visuales Necesarios para Publicar
```
Apple App Store:
- App Icon: 1024x1024 px (PNG, sin transparencia, sin canal alfa)
- Screenshots: 6.7" (1290x2796), 6.5" (1242x2688), 5.5" (1242x2208)
- App Preview (opcional): video de 15-30 segundos

Google Play Store:
- App Icon: 512x512 px (PNG con transparencia)
- Feature Graphic: 1024x500 px (PNG)
- Screenshots: 1080x1920 px mínimo (2-8 imágenes)
- TV Banner (si soporta TV): 1280x720 px

Ambos:
- Política de privacidad en web (HTTPS)
- Descripción corta (80 chars Google, 30 chars Apple)
- Descripción larga (4000 chars Google)
- Categoría: Games > Simulation / Educational
- Rating de contenido: 6+ años
```
